The workbench

Seven verbs. One contract.

Every command speaks the same versioned JSON — schema, command, ok — with absolute spans and 1-based capture groups. Humans get quiet, readable output; agents get structure; nothing changes between releases without a version bump.

For agents

A contract, not a screenscape

Exit codes mean something, errors are single-line, absent groups are null — never missing keys. Point any tool loop at it.

{ "schema": "regexmate/v1", "command": "match", "ok": true, "matches": [{ "value": "a@b", "start": 5, "end": 8, "groups": [{ "index": 1, "value": "a" }, …] }] }

For humans

Explain, in plain language

Inherited a pattern you don't trust? explain walks it part by part — in English or 中文.

$ regexmate explain '(?:\d{2,4}|[a-z]+)(?=x)' 1. [group] (?:\d{2,4}|[a-z]+) ← Non-capturing group: Digit × {2,4} | Character class × + 2. [lookaround] (?=x) ← Positive lookahead: Literal x

Iterate

Test before you ship

Assert positives and negatives; lint catches ReDoS and dead branches with --strict as a CI gate.

✓ "2026-09-28" ✓ "2026-13-01" ✗ "2026-9-28" — no match found Passed 2 of 3 case(s).

Native

A desktop app, not a wrapper

Windows releases ship regexmate-gui — a native WinUI 3 app: pattern on top, matches and explanation beside a live railroad diagram. Same core as the CLI, embedded in the process — no server, no Electron.

$ tar -tf regexmate-macos.tar.gz regexmate-gui regexmate lib/

Stays current

Updates itself

One command pulls the latest release, verifies the published checksum and swaps the binary in place — while it runs. Also on Homebrew: brew install turinglambdaai/tap/regexmate.

$ regexmate update Verifying checksum… Updated to v1.3.0.

Agents

Built for the tool loop

MCP server

Seven tools with input schemas, over stdio JSON-RPC. Add one block to your agent config — no glue code.

{ "mcpServers": { "regexmate": { "command": "regexmate", "args": ["mcp"] } } }

Exit codes that mean something

0ok — match found / pattern valid / replacement done
1invalid regular expression
2usage error (bad flag, unknown command)
3valid pattern, zero matches / zero replacements / failing cases

Scriptable to the core

Text comes from an argument or stdin. NO_COLOR and REGEXMATE_LANG are honored; --lang switches output language.

# stdin in, JSON out — chain it anywhere cat access.log | regexmate match 'ERROR \d+' - --json # exit code 3 = valid regex, no match regexmate match 'ERROR' "$log" --json || code=$? # the contract describes itself regexmate schema

Spans are absolute and [start, end). Capture groups are 1-based; absent groups are null — never missing keys.

Install

Up and running in a minute

Binary

Windows, Linux and macOS. Unzip and run — no runtime needed.

Homebrew

macOS on Apple Silicon, from the TuringLambdaAI tap.

brew install turinglambdaai/tap/regexmate

Racket

Already running Racket? Install straight from the repository.
