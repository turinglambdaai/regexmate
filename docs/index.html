工作台

七个动词，一套契约。

所有命令共用同一套版本化 JSON——schema、command、ok——绝对区间、从 1 计数的捕获组。人类得到安静的输出，agent 得到结构，版本变更绝不悄悄破坏契约。

为智能体

是契约，不是屏幕刮取

退出码有语义、错误保持单行、缺席组是 null 而非缺键。任何工具循环直接接入。

{ "schema": "regexmate/v1", "command": "match", "ok": true, "matches": [{ "value": "a@b", "start": 5, "end": 8, "groups": [{ "index": 1, "value": "a" }, …] }] }

为人类

人话解释

接手一个不敢信的正则？explain 逐段讲清楚——英文或中文。

$ regexmate explain '(?:\d{2,4}|[a-z]+)(?=x)' 1. [group] (?:\d{2,4}|[a-z]+) ← Non-capturing group: Digit × {2,4} | Character class × + 2. [lookaround] (?=x) ← Positive lookahead: Literal x

原生

桌面应用，不是套壳

每个平台的发布包都带 regexmate-gui——原生桌面应用（SwiftUI / WinUI 3 / GTK4），边输入边求值：匹配直接高亮在样本文字里，旁有解释、lint 与实时铁路图。与 CLI 同一核心、进程内嵌——无服务、无 Electron。

$ tar -tf regexmate-macos.tar.gz regexmate-gui.app regexmate lib/

保持最新

自己更新自己

一条命令拉取最新发布、验证 Ed25519 签名的更新清单与下载校验和、运行中原地换装。

$ regexmate update Downloading regexmate-macos-arm64.tar.gz (signature and checksum verified) … Updated.

智能体

为工具循环而生

MCP server · also on agents-guide

七个带输入 schema 的工具，走 stdio JSON-RPC。配置里加一段即可——零胶水代码。

{ "mcpServers": { "regexmate": { "command": "regexmate", "args": ["mcp"] } } }

有语义的退出码

0成功——有匹配 / 语法有效 / 完成替换
1正则表达式无效
2用法错误（错误选项、未知命令）
3语法有效但零匹配 / 零替换 / 用例失败

脚本友好到骨子里

文本可来自参数或 stdin。支持 NO_COLOR 与 REGEXMATE_LANG；--lang 切换输出语言。

# stdin in, JSON out — chain it anywhere cat access.log | regexmate match 'ERROR \d+' - --json # exit code 3 = valid regex, no match regexmate match 'ERROR' "$log" --json || code=$? # the contract describes itself regexmate schema

区间为绝对下标、[start, end) 半开。捕获组从 1 计数；缺席组是 null——绝不缺键。
